# Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic with addition, subtraction, multiplication, and division
- Decimal numbers
- `%` remainder operation
- `AC` clears the display
- `DEL` removes the last character
- Responsive viewport settings for mobile browsers

## Run the project

No installation or build step is required. Open `index.html` in a web browser, or serve the project folder with a local development server such as VS Code Live Server.

The Poppins font is loaded from Google Fonts, so an internet connection is needed for that font. The page still has a sans-serif fallback when offline.

## Project files

- `index.html` provides the calculator layout and loads the other files.
- `style.css` contains the calculator styling.
- `script.js` handles button clicks and calculations.
